# 步步官網調整紀錄（2026-09-19）

## 資訊架構
- 首頁：單一預約入口、三項核心服務、三項交付原則、精選知識、較小的服務夥伴入口。
- 服務與收費：六項既有服務維持，各自連到詳細範圍及詢價。
- 預約：單頁收集服務、姓名、手機、區域，日期與細節選填；沿用現有伺服器驗證、資料庫、防重複與後台。
- 搬家知識：15 篇原創筆記，五類分類、全文關鍵字篩選、文章目錄及相關文章。
- 服務夥伴：品牌合作、居家整聊室課程兩個入口。課程在原主辦單位完成報名。
- 案例：只顯示已授權公開的真實資料；首頁無案例時省略該段，不用虛構資料填版。

## 已確認的方案資料
- 搬家每車 NT$4,200 起；整理每人 NT$800，時長另確認。
- 自備車輛方案加盟金 NT$100,000。
- 購車方案總額 NT$2,500,000，使用者明確確認包含車款。
- 購車方案由加盟主購置持有車輛；總部協助融資申請，不承諾核貸。
- 可自行接案及接受總部案件媒合；不承諾派案量、收入或回本。
- 「車格」僅確認為其他車輛營運安排，尚無具體內容，因此未列出牌照、停車位等承諾。

## 正式招募與對外營運前仍需確認
目前頁面只受理意向，不能據此判斷任何特定靠行或加盟制度合法。應將實際契約、公司運輸業資格、車輛及駕駛資格交由熟悉運輸業的律師及轄區監理機關確認。

待明訂事項：10 萬元及 250 萬元的含稅與項目明細、持續費用、車型配備、車籍與所有權安排、融資利息與費用、保險、接案與承運責任、分潤結算、品牌授權、合作限制及退場機制。
