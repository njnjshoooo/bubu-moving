# 步步搬家網站

原始品牌 Logo 與情境圖片取自使用者提供的 Bubu_v7_Platform.pdf。圖片為文件已註記的 AI 情境示意，不作真實案例或客戶評價。網站不公開商業計畫內的募資、財務或內部策略。

## 本版已實作

- 繁體中文品牌首頁、六項服務頁、手機版配置、服務說明與詢價資料告知。
- 搬家每車 NT$4,200 起；整理每人 NT$800，未擅自假定按小時計價。
- 多服務兩步詢價；動態欄位、服務同意、伺服器驗證、D1 永久保存、重複請求去重、缺件狀態、案件編號及摘要下載。
- 受伺服器端登入信箱白名單保護的詢價工作台、搜尋／篩選、追蹤狀態、內部紀錄、版本衝突防護及 CSV 匯出。
- 讀取、匯出及變更稽核；公開表單不提供可猜測案件 ID 的查詢接口。
- WebMCP 僅協助勾選服務，不代替客戶提交。

## 正式開放接單前需要營運資料

1. 接單電話／LINE、服務縣市及公司對外資訊。
2. 每人 800 元的時間單位、最低時數／人數；每車車型、容量、基礎範圍、稅別及加價條件。
3. ChatGPT 登入管理員信箱，設定成 Sites 執行環境 `BUBU_ADMIN_EMAILS`（逗號分隔）。空值時所有後台存取一律拒絕。
4. 確認公開隱私告知內容、保存期限、個資窗口及正式服務條款。
5. 目前 Sites 維持建立時的擁有者私有存取。確認正式營運資料後再切換公開服務。

## 與完整平台規格的差距

本版是官網與可保存的詢價管理，不是整份 P0 交易／調度／財務平台。以下尚未實作或未介接，不能視為已驗收：客戶手機 OTP、照片私有上傳、版本化正式報價及契約確認、訂單／工單、合作司機及車輛資格／培訓、衝突派單、現場驗收、收款核銷／退款雙人核准／供應方結算、包材庫存、定期工單、CRM／派單／SCM 同步、通知、金流、發票、備份復原演練與負載 SLA。已轉訂單狀態僅表示人工在外部正式系統完成交接，不會自動生成交易。

文件中的 D01–D10 是來源規格的決策清單，並非已取得的營運設定。未核定收款與契約內容，不啟用扣款或確定價。

## 開發與部署

標準 Vinext / React / Cloudflare Workers / D1。使用 Sites 技能管理建置及部署。`npm run dev` 啟動本機開發；`npm run build` 產生 `dist/server/index.js`。`npm run db:generate` 產生 Drizzle schema-only 遷移。本機資料不會隨部署上傳。

`db/schema.ts` 定義 inquiries 與 audit_log。`lib/server.ts` 集中 DB、登入授權與回應。`app/api/inquiries` 為公開寫入接口；`app/api/admin` 為受保護讀寫及匯出。生產環境以 Sites 驗證入口提供身份 header，勿將 Worker 繞過驗證代理直接暴露。

`.env.example` 提供必要設定，真實值只放本機未追蹤檔或 Sites runtime。空白管理員設定為安全拒絕。正式 runtime 不要使用本機 seedy@sites.test 帳號。
